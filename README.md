**KALAtech** is an icon-first, voice-assisted multimodal mobile web application designed to bridge the digital and market divide for marginalized Indian craftspeople and handloom weavers.

---

## Quick Start (PowerShell)

```powershell
# 1. Navigate to project
cd c:\Users\pushp\.gemini\antigravity-ide\scratch\artsians-SIH

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open **`http://localhost:3000`** in your browser.
